# 2026-10-25

## 【主工程】编辑器草稿保留规则收敛到「只有回复主楼」

原来用 `_sessionWasEditing`（是否编辑会话）决定关闭时清不清空，引用回复被漏在外面
（它既不是编辑也不是回复主楼，于是草稿被保留下来，下次引用别的楼层时串味）。

现在统一成一条判据，写在 `ComposeSheet.Hide()` 动画结束处：

```csharp
var keepDraft = !_resetOnHide && Mode == EditorMode.ReplyToTopic;
_resetOnHide = false;
if (!keepDraft) Editor.Reset();
Editor.ClearPreview();
```

| 场景 | 关闭行为 |
| --- | --- |
| 回复主楼（ReplyToTopic） | **保留草稿** |
| 引用他人（ReplyToPost） | 清空（预填的是那一层的引用块，留着会串到下次引用） |
| 编辑主题 / 编辑回复 | 清空（原帖还在服务器上） |
| 任何模式发送成功 | 清空（`_resetOnHide`） |

`_sessionWasEditing` 字段随之删掉。

## 【主工程】发送防重

原来的 `if (_isSending) return;` 只能挡住"请求在飞"这一种，两个窟窿：

1. **发送成功后**（`finally` 立刻解锁）→ 浮层还在往下滑的 200ms 里面板仍然可点，
   内容也还没清空，连点第二下就会**重复发一条**；
2. 请求飞行途中用户关了浮层，响应回来时 `Hide()` 是空操作（已经关了），
   内容没被清、`_resetOnHide` 挂着。

改法：
- 入参校验前置成三重：`_isSending || _isClosing || !_isOpen` → 直接 return；
- `finally` 里**只有失败才解锁**（`if (!sent)`），成功一路锁到关闭，
  `Show()` 里再复位 `_isSending` / `SendButton.IsEnabled`；
- 成功后如果 `_isOpen` 已为 false，就地 `Editor.Reset() + ClearPreview()`，不再依赖收起动画。
