## 【修复】编辑回复不该校验标题 + 匿名框置灰

用户报：编辑「我的回复」时报「标题不能为空」。

**原因**：`EditPostRequest.Title` 是必带字段，服务端拿它覆盖主题标题 —— 所以编辑回复**也要回传主题原标题**，
只是界面上不给改。我上一版把它当成"回复没有标题"，把值清空了，于是校验失败。
（SketchPage 里 `SetTitle.Text = HintText`（= TopicInfo.Title）两种编辑模式都填，就是这个道理。）

改法：
- `SetTitleEditing(bool visible, string? title)` —— **visible 只控制能不能改，值照样写进去**；
  只有回复模式（传 null）才清空。
- `ConfigureForMode`：`SetTitleEditing(editingTopic, editing ? InitialTitle : null)`；
  `TopicPage.OpenEditorForEdit` 两种编辑模式都 `InitialTitle = TopicInfo.Title`。
- 标题校验只留 `Mode == EditMyTopic`。
- 新增 `SetAnonymousEditable(bool)`：编辑模式把 `AnonCheck` 置灰 + tooltip「编辑时无法修改匿名状态」
  （`EditPostRequest` 没有 IsAnonymous 字段）。

## 【主工程】接入「引用他人帖子」

菜单里的 QUOTE 分支不再 `Frame.Navigate(SketchPage)`，改成开浮层：

```csharp
var quote = $"[quote]{header}{reply.Content}[/quote]";   // header 与 SketchPage 完全一致
ComposeOverlay.Mode = EditorMode.ReplyToPost;
ComposeOverlay.ParentId = reply.Id;          // 只有 ReplyToPost 能带 parentId
ComposeOverlay.InitialTitle = "";            // 引用回复没有标题
ComposeOverlay.HintText = $"引用{reply.UserName}的回复";
ComposeOverlay.PrefillQuote(quote);
ComposeOverlay.Show();
```

- `ComposeSheet.HintText`（新属性）：回复模式的标题栏文案，为空才退回「回复主题」。
  `writereply_Click` 里要显式清空，否则上次引用的「引用某某」会留在普通回复的标题上。
- `ComposeEditor.PrefillQuote(quote)`：**语言强制切 UBB**（引用串就是 UBB，不管原帖是不是 MD），
  末尾补一个换行、光标落到文末 —— 和 SketchPage 一样。`ParentId` 让回帖挂在被引用楼层下面。

### 顺手改掉的草稿逻辑

原来靠 `_editingLastTime` 在"下次打开"时清编辑残留，但 `PrefillQuote` 是在 `Show()` 之前填内容的，
会被那次清理直接抹掉（引用块消失）。改成**关闭时清理**：

```csharp
if (_resetOnHide || _sessionWasEditing) Editor.Reset();   // 发送成功 / 编辑取消 → 清
Editor.ClearPreview();
```

只有"回复草稿"才保留。这样顺序问题从根上没了。
